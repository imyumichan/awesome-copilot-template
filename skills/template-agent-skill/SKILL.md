# Template Agent Skill

This skill serves as a template for creating new agent skills within the AI assistant plugin. It provides the basic structure and guidelines for defining skill behavior and integration with the plugin system.

## When to Use

Use this template skill as a starting point when creating new agent skills for the AI assistant plugin. It is particularly useful for defining consistent structure, behavior, and integration patterns across different skills.

## Workflow

The typical workflow for using this template skill involves the following steps:

- **Step 1: Define Skill Behavior** — Determine the specific behavior or capability that the new skill should provide.
- **Step 2: Implement Skill Logic** — Create the necessary scripts, prompts, or other components to implement the defined behavior.
- **Step 3: Integrate with Plugin** — Ensure the skill is properly integrated with the AI assistant plugin, including updating any relevant configuration files.
- **Step 4: Test Skill** — Verify that the skill functions as expected within the plugin environment.
- **Step 5: Document Skill** — Update the `SKILL.md` with relevant usage instructions, examples, and any other necessary documentation.
